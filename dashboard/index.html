CONFIGURAÇÃO DE CAMPO

Rede dos dispositivos

Use os nomes mDNS quando possível: esp32-cam.local e robo-c6.local. Eles continuam iguais mesmo quando o roteador troca o IP por DHCP. O C6 trabalha somente em 2,4 GHz; uma rede marcada 5G não funcionará.
